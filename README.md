# 🛒 ShopEase – Full Stack E-Commerce Application

## 📌 Project Overview

ShopEase is a full-stack e-commerce application developed as part of my internship. The project allows users to register, log in, browse products, manage their wishlist and cart, save delivery addresses, and place orders.

---

## 🚀 Features

- 👤 User Registration
- 🔐 User Login with JWT Authentication
- 📦 View Products
- ❤️ Wishlist Management
- 🛒 Shopping Cart
- 📍 Address Management
- 📑 Order Placement
- 📜 Order History

---

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Yashashwini-MV/Intern-ecommerce-Yashashwini.git
```

### Backend

```bash
cd backend
npm install
npm run start:dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🔑 Authentication

JWT-based authentication is implemented using Passport.js. Protected routes require a valid JWT token.
